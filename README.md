# 🛏️ Bedsheets Website

A modern and responsive bedsheets website built with **React**, **Vite**, and **Tailwind CSS**. The project focuses on creating a clean, elegant, and responsive user interface for showcasing bedsheet products.

🔗 **Live Website:** https://as-0607.github.io/bedsheets-website/

## 🚀 Getting Started

### Prerequisites

Make sure you have **Node.js** installed on your computer.

### 1. Clone the repository

```bash
git clone https://github.com/as-0607/bedsheets-website.git
```

### 2. Navigate to the project directory

```bash
cd bedsheets-website
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Vite will provide a local development URL in the terminal, usually:

```text
http://localhost:5173
```

### 5. Build for production

```bash
npm run build
```

## ⚛️ React

The website is built using React and follows a component-based architecture.

Reusable components are separated from pages to make the application easier to maintain and expand.

For example:

```text

├── Navbar
├── Footer
├── ProductCard
└── ...

pages/
├── Home
├── Collections
├── About
└── Contact
```
